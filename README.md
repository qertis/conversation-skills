# Навыки общения

В каталоге `skills/` лежат пять самостоятельных навыков для рабочих знакомств, самопрезентации и подготовки к разговорам. Каждый устанавливается отдельно. Все необходимые инструкции и шаблоны находятся в папках навыков.

| Навык | Когда использовать |
| --- | --- |
| [`networking-plan`](skills/networking-plan/SKILL.md) | Поставить цель, выбрать площадки и людей, спланировать первый контакт. |
| [`networking-conversation`](skills/networking-conversation/SKILL.md) | Подготовить вопросы к встрече, провести репетицию или разобрать разговор. |
| [`self-introduction`](skills/self-introduction/SKILL.md) | Написать короткую устную или более подробную письменную самопрезентацию. |
| [`communication-strengths`](skills/communication-strengths/SKILL.md) | Найти сильные стороны и подкрепить их примерами из опыта. |
| [`communication-blocks`](skills/communication-blocks/SKILL.md) | Разобрать мысль, которая мешает общаться, и выбрать следующий шаг. |

## Установка в Codex

1. Найди нужный навык в `skills/`. Для установки всего комплекта возьми все пять папок.
2. Скопируй каждую папку целиком в `.agents/skills/` в корне целевого проекта. Для личной установки во все проекты используй `~/.agents/skills/`. Если папка с таким именем уже есть, сначала сравни её с исходной и сохрани локальные правки.
3. Проверь структуру копии. Например, в `.agents/skills/networking-plan/` должны лежать `SKILL.md`, `agents/openai.yaml` и `references/planning.md`.

## Как проверить установку

1. Открой целевой проект в Codex. В CLI вызови `/skills`, а в настольном приложении открой раздел **Skills**. Если новый навык не появился, перезапусти Codex и проверь, что открыт нужный проект.
2. Выбери установленный навык и дай ему конкретную задачу. Например, в CLI можно написать так.

   > Используй $networking-plan и составь план знакомств с коллегами из смежных команд на четыре недели.

Для другого ИИ-агента с поддержкой Agent Skills используй каталог, который указан в документации этой среды, и сохрани ту же структуру папок. Для разового применения без установки передай агенту путь к нужному `SKILL.md` и попроси использовать его вместе с указанными в нём справочными файлами.
